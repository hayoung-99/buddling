처음 한 번만

처음 열 때 컴퓨터가 한 번 확인해요. 아래대로 하면 다음부터는 그냥 열려요.

macOS

  1. 받은 앱을 응용 프로그램 폴더로 옮겨요.
  2. 앱을 우클릭하고 열기를 눌러요. 더블클릭이 아니라 우클릭이에요.
  3. 뜨는 창에서 열기를 한 번 더 눌러요.
  4. 그래도 막히면 시스템 설정 → 개인 정보 보호 및 보안에서 아래쪽 확인 없이 열기를 눌러요.

Windows

  1. 받은 파일을 두 번 눌러요.
  2. 파란 창이 뜨면 추가 정보를 눌러요.
  3. 아래에 나타나는 실행을 누르면 설치가 이어져요.

궁금한 것

궁금할 만한 것

tap-tap이 뭔가요?

바탕화면에 3D 동물 캐릭터를 띄워 두는 macOS·Windows 앱이에요. 내 캐릭터를 누르면 같은 팀 사람들 화면에서 캐릭터가 춤을 춰요. 무료이고 가입도 없어요.

팀원도 받아야 하나요?

네. 서로의 바탕화면에 캐릭터가 있어야 신호가 오가요. 한 사람이 팀을 만들면 여섯 글자 초대코드가 나오고, 나머지는 그 코드만 넣으면 돼요.

정말 무료인가요?

네. 광고도 유료 기능도 없어요. 이메일도 비밀번호도 받지 않고요.

혼자 써도 되나요?

캐릭터는 팀마다 한 마리씩 떠서 팀은 하나 있어야 해요. 혼자 만든 팀도 팀이라 캐릭터는 그대로 살아요. 콕 찌를 상대가 아직 없을 뿐이에요. 팀은 최대 3개, 한 팀에 5명까지예요.

회사 컴퓨터에 깔아도 될까요?

오가는 건 누가 눌렀다는 신호와 이름뿐이에요. 화면에 뭐가 떠 있는지도, 파일도 밖으로 나가지 않아요. 설치할 때 관리자 권한도 묻지 않고요.

처음 열 때 창이 떠요. 안 열리면요?

처음 한 번만 그래요. 위의 순서대로 하면 다음부터는 그냥 열려요. 그래도 미덥지 않으면 만드는 코드를 전부 공개해 뒀으니 직접 읽어 보셔도 돼요.

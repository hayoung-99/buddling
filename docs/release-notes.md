바탕화면 위 3D 동물 친구. 내 캐릭터를 클릭하면 팀원들의 캐릭터가 춤을 춥니다.

## 무엇을 받아야 하나요

| 쓰는 컴퓨터 | 받을 파일 |
|---|---|
| Mac (M1·M2·M3·M4) | `tap-tap-{version}-arm64.dmg` |
| Mac (2020년 이전 인텔) | `tap-tap-{version}-x64.dmg` |
| Windows | `tap-tap-{version}-setup.exe` |

내 맥이 어느 쪽인지 모르겠다면 **  → 이 Mac에 관하여**를 열어 보세요.
"칩"이라고 적혀 있으면 arm64, "프로세서"라고 적혀 있으면 x64 입니다.

## 처음 열 때 경고가 뜹니다 — 정상입니다

이 앱은 **코드 서명을 하지 않았습니다.** 서명은 애플·마이크로소프트에 매년 돈을 내고
받는 증명서인데, 아직 그 단계가 아닙니다. 그래서 운영체제가 "만든 사람을 확인할 수
없다"고 알려 줍니다. 넘기는 방법은 이렇습니다.

### macOS

1. 받은 앱을 **응용 프로그램** 폴더로 옮깁니다
2. 앱을 **우클릭 → 열기** (더블클릭이 아니라 **우클릭**입니다)
3. 뜨는 창에서 **열기**를 한 번 누르면 다음부터는 그냥 열립니다

그래도 "손상되었다"고 나오면 터미널에서 아래를 한 번 실행하세요.

```bash
xattr -dr com.apple.quarantine /Applications/tap-tap.app
```

### Windows

파란 **"Windows의 PC 보호"** 창이 뜨면 **추가 정보 → 실행**을 누르면 됩니다.

## 쓰기 시작하려면

계정 가입이 없습니다. 앱을 열고 이름을 정한 뒤 팀을 만들면 **6자리 초대코드**가
나옵니다. 팀원에게 그 코드를 알려주면 끝입니다.

## 다음 버전부터는

**Windows 는 자동으로 업데이트됩니다.** 새 버전이 나오면 앱이 조용히 받아 두었다가
"지금 적용하기"를 누르면 갈아끼웁니다. 안 눌러도 다음에 앱을 종료할 때 적용됩니다.

macOS 는 코드 서명이 없으면 자동 설치가 불가능해서, 새 버전이 나왔다는 안내만
뜹니다. 그때 이 페이지에서 다시 받아 주세요.
